# وصف مشروع متجر إلكتروني

## نظرة عامة

هو مشروع متجر إلكتروني متكامل تم تطويره باستخدام Laravel، وهو إطار عمل PHP متقدم. المشروع يوفر واجهة متعددة اللغات (العربية والإنجليزية) مع دعم RTL/LTR، ويحتوي على نظام إدارة متكامل للمستخدمين والمنتجات والطلبات والدعم الفني.

## الميزات الرئيسية

### 1. نظام المستخدمين
- تسجيل الدخول والتسجيل
- لوحة تحكم للمستخدمين
- إدارة الملف الشخصي
- نظام الأدوار والأذونات (المدير، موظف الدعم، العميل العادي)

### 2. نظام المنتجات
- عرض المنتجات حسب التصنيفات
- البحث عن المنتجات
- عرض المنتجات بأسعار مخفضة
- إضافة المنتجات إلى السلة
- إضافة المنتجات إلى قائمة الرغبات

### 3. نظام الطلبات
- متجر افتراضي للمنتجات
- إدارة السلة
- نظام الدفع
- تتبع الطلبات
- نظام المراجعات

### 4. نظام الدعم الفني
- نظام دردشة مباشر
- نظام تذاكر الدعم
- لوحة تحكم لموظفي الدعم
- قوالب الردود الجاهزة

### 5. لوحة تحكم الإدارة
- إدارة المنتجات
- إدارة المستخدمين
- إدارة الأدوار والأذونات
- إدارة الطلبات
- إدارة الدعم الفني
- تقارير وإحصائيات

## الهيكل العام للمشروع

### المسارات (Routes)
- المسارات العامة (يمكن للزوار الوصول إليها)
- المسارات المحمية (تتطلب تسجيل الدخول)
- مسارات لوحة تحكم الإدارة
- مسارات نظام الدعم الفني

### المشاهدات (Views)
- صفحات المتجر العامة
- صفحات لوحة تحكم المستخدم
- صفحات لوحة تحكم الإدارة
- صفحات نظام الدعم الفني

### النماذج (Models)
- Product (المنتجات)
- User (المستخدمين)
- Order (الطلبات)
- OrderItem (عناصر الطلب)
- SupportSession (جلسات الدعم)
- SupportMessage (رسائل الدعم)
- Role (الأدوار)
- Permission (الأذونات)

### المتحكمات (Controllers)
- ProductController (إدارة المنتجات)
- AuthController (المصادقة)
- CartController (إدارة السلة)
- AdminController (لوحة تحكم الإدارة)
- SupportController (نظام الدعم الفني)
- SupportAdminController (لوحة تحكم موظفي الدعم)

## الميزات التقنية

### 1. نظام اللغات
- دعم اللغتين العربية والإنجليزية
- دعم اتجاه النص (RTL/LTB)
- نظام الترجمة القائم على الملفات

### 2. التصميم والواجهة
- تصميم متجاوب يعمل على جميع الأجهزة
- استخدام CSS مخصص
- تصميم مستوحى من واجهات Amazon

### 3. الأمان
- نظام المصادقة القوي
- نظام الصلاحيات والأدوار
- حماية المسارات الحساسة

### 4. قاعدة البيانات
- استخدام SQLite للبيانات (للبساطة)
- علاقات بين النماذج
- تصميم قاعدة بيانات متعدد الأغراض

## الواجهات الرئيسية

### 1. واجهة المتجر الرئيسية
- عرض المنتجات
- البحث والتصفية
- عرض المنتجات المميزة والعروض

### 2. واجهة لوحة تحكم المستخدم
- عرض الطلبات السابقة
- إدارة السلة وقائمة الرغبات
- تعديل الملف الشخصي

### 3. واجهة لوحة تحكم الإدارة
- إدارة المنتجات
- إدارة المستخدمين والأدوار
- إدارة الطلبات
- إدارة نظام الدعم الفني

### 4. واجهة نظام الدعم الفني
- الدردشة المباشرة مع العملاء
- إدارة تذاكر الدعم
- لوحة تحكم لموظفي الدعم

## الخطوات المستقبلية المقترحة

1. إضافة طرق دفع إضافية
2. تطوير تطبيق جوال
3. إضافة نظام إشعارات
4. تحسين الأداء وتقليل حجم الصفحات
5. إضافة نظام مراجعات متقدم
6. دعم المزيد من اللغات
7. إضافة نظام برمجة للمهام المجدولة

## خلاصة

هذا المشروع يمثل متجر إلكتروني متكامل يمكن استخدامه كقاعدة أساسية لتطوير متاجر إلكترونية متقدمة. يحتوي على جميع المكونات الأساسية اللازمة لمتجر إلكتروني ناجح مع إمكانية التوسع والتحديث المستقبلي.
